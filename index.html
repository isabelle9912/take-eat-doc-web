Escopo do Projeto

O Take Eat é um aplicativo o qual tem o objetivo de combater o desperdício de alimentos e a fome, através do bom senso dos doadores de alimentos, distribuidores (como ONGs ou instituições de caridade), apoiadores e entregadores. Essa tecnologia permite que doadores cadastrem produtos que estarão disponíveis para doação, os distribuidores poderão ter acesso a esses produtos e montar "pedidos" para coletá-los e distribuí-los a quem mais precisa, os, apoiadores poderão contribuir financeiramente através de um sistema de "carteira", além dos entregadores, que serão responsáveis pela logística de transporte dos alimentos.

O aplicativo permitirá o gerenciamento de diferentes perfis de usuários, cada qual com funcionalidades específicas para seu papel no fluxo de doação. Ele controla desde a disponibilização do produto pelo doador até a entrega final, passando pela gestão de pedidos, carrinho de compras, entregas e transações financeiras (extrato e carteira).

Requisitos do Sistema

Esta seção detalha as funcionalidades que o sistema deve executar, ou seja, o que ele deve fazer. São as ações e serviços que os usuários podem realizar na plataforma.

  • RF01: Permitir o cadastro de diferentes tipos de usuários (Doador, Distribuidor, Apoiador, Entregador).
  • RF02: Permitir que os usuários se autentiquem com email e senha.
  • RF03: Permitir que usuários "Doador" cadastrem e gerenciem produtos para doação.
  • RF04: Permitir que usuários "Distribuidor" visualizem os produtos disponíveis.
  • RF05: Permitir que usuários "Distribuidor" adicionem produtos a um carrinho.
  • RF06: Permitir que usuários "Distribuidor" criem um pedido a partir dos itens do carrinho.
  • RF07: Registrar os pedidos, associando-os a um distribuidor e aos produtos selecionados.
  • RF08: Gerenciar o status de um pedido (ex: pendente, em trânsito, entregue).
  • RF09: Gerenciar as entregas, associando um pedido a um entregador e a um veículo.
  • RF10: Permitir que usuários "Apoiador" gerenciem uma carteira virtual para doações.
  • RF11: Registrar um extrato de transações para os apoiadores.
  • RF12: Permitir que usuários "Entregador" gerenciem seus veículos.

Esta seção descreve os critérios de qualidade e as restrições do sistema. Eles não se referem a uma funcionalidade específica, mas sim a como o sistema deve operar.

  • RNF01: A interface do sistema deve ser intuitiva e de fácil utilização.
  • RNF02: O sistema deve ser responsivo, adaptando-se a diferentes tamanhos de tela.
  • RNF03: O sistema deve garantir a segurança dos dados dos usuários.
  • RNF04: O sistema deve ter um tempo de resposta rápido (páginas em < 3s).
  • RNF05: O sistema deve ser compatível com os navegadores mais populares.
  • RNF06: O sistema deve ter alta disponibilidade (24/7).

Processos e Atores

Processo de Doação e Entrega (BPMN)

O fluxo a seguir representa o principal processo de negócio do Take Eat, desde o cadastro de um produto até sua entrega final. Passe o mouse sobre cada etapa para destacá-la.

1. Doador cadastra um novo produto para doação.
2. Sistema disponibiliza o produto na plataforma.
3. Distribuidor navega pelos produtos disponíveis.
4. Distribuidor adiciona os produtos desejados ao carrinho.
5. Distribuidor finaliza o pedido.
6. Sistema cria o pedido e notifica os entregadores.
7. Entregador aceita o pedido de entrega.
8. Entregador retira o produto com o Doador.
9. Entregador transporta o produto até o Distribuidor.
10. Sistema atualiza o status para "Entregue".

Casos de Uso

Os casos de uso descrevem as interações entre os atores (usuários) e o sistema para atingir um objetivo. Clique em cada um para ver os detalhes.

Glossário

Definições dos principais termos utilizados no projeto para garantir um entendimento comum.

  • Apoiador: Usuário que contribui financeiramente para a plataforma.
  • Doador: Usuário que disponibiliza alimentos para doação.
  • Distribuidor: Organização que recebe os alimentos para distribuir.
  • Entregador: Usuário responsável pelo transporte dos alimentos.
  • Take Eat Coin: Moeda virtual da plataforma.
  • Pedido: Solicitação de um Distribuidor para coletar produtos.
  • DER: Diagrama de Entidade-Relacionamento.

Regras de Negócio

As regras de negócio são diretrizes e restrições que definem ou restringem as operações do sistema, garantindo a integridade e a lógica do processo.

  • RN01: Um usuário deve ter um e apenas um tipo de perfil (Doador, Distribuidor, etc.).
  • RN02: Para cadastrar um produto, o usuário deve ser do tipo "Doador".
  • RN03: Um produto deve estar associado a um único Doador.
  • RN04: Para criar um pedido, o usuário deve ser do tipo "Distribuidor".
  • RN05: Um pedido deve estar associado a um único Distribuidor.
  • RN06: Um pedido pode conter vários produtos, e um produto pode estar em vários pedidos.
  • RN07: Uma entrega deve estar associada a um único pedido e a um único entregador.
  • RN08: Um entregador deve cadastrar pelo menos um veículo para poder realizar entregas.
  • RN09: Apenas usuários do tipo "Apoiador" podem ter uma carteira e um extrato.
  • RN10: O status de um pedido deve seguir o fluxo: Pendente -> Em trânsito -> Entregue.
